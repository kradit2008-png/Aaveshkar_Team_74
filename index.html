Problem 4.1 Architecture & Threat Defense Knowledge Hub

Universal Foreign Key

Routine sign-ups turn an email into a global database foreign key. Data aggregators (Acxiom, Experian) stitch profiles across breaches using SHA256(email) as the join index.

Attribution Void

Without isolated addresses, when an inbox receives marketing spam or spear-phishing lures, the user has zero technical mechanism to prove which organization leaked or sold their contact information.

Phantom Retention

Clicking "Unsubscribe" only halts automated marketing sends; it does NOT remove personal data from vendor backups, data lakes, or analytics silos.

Plus-Addressing Flaw

user+tag@gmail.com is trivially stripped by modern data hygiene scripts via regex: s/\+.*@/@/, instantly exposing the canonical inbox.

Catch-All Domain Flaw

service@userdomain.com leaks the root apex domain. Graph databases easily cluster all registrations under the same owner using DNS/WHOIS records.

Burner Mail Flaw

10-minute temporary inboxes destroy account recovery continuity and are heavily blacklisted by anti-fraud risk engines (Sift, IPQualityScore).
